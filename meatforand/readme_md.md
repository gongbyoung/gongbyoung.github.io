# 🥩 미트포앤(meatforand) 사내 물류·발주·재고·배차 통합 관리 시스템

미트포앤 사내 업무 효율화를 위해 구축된 통합 물류 관리 웹 어플리케이션입니다. 카카오톡 발주 메시지 자동 분할·합산, ERP 엑셀 재고 파악, 6열 바둑판 발주 확인, 낱개 소분 체크리스트, 창고 3단 랙 및 바코드 입출고, VWorld 지도 기반 스마트 자동 배차까지 단일 웹 인터페이스에서 통합 제공합니다.

> ⚠️ **보안 주의사항:** GitHub 저장소가 **Public(공개)** 상태일 경우 외부인도 `https://gongbyoung.github.io/clients.csv` 주소로 거래처 주소·연락처·비밀번호를 내려받을 수 있습니다. 데이터 보안이 중요한 경우 GitHub에 업로드하지 않고 **로컬 CSV 파일 선택 방식**을 권장합니다.

## 📖 시스템 상세 사용 설명서

### ⚙️ 공통 인터페이스 (상단 컨트롤 바 & 하단 플로팅 독)

* **상단 컨트롤 바:**
  * **납품 기준 날짜 / 판별 모드:** `🧠 스마트 납품일 자동판별` 모드는 정오(12:00) 이전 발주는 당일, 정오 이후 발주는 익일로 자동 파싱합니다. 필요 시 `🚚 당일만` 또는 `⏭️ 익일만`으로 강제 고정할 수 있습니다.
  * **`[🔍 발주만: ON]` / `[🏢 거래처: OFF]`:** 잡담·계근지를 제하고 순수 발주 항목만 정기 필터링합니다.
  * **`[📷 바코드]`:** 전 메뉴 공통 바코드 스캐너 모달을 호출합니다.
  * **디바이스 / 폰트 크기:** `📱 모바일` / `📟 태블릿` / `🖥️ PC` 뷰 모드 조절 및 slider로 UI 비율(100%~150%)을 즉시 조절할 수 있습니다.
* **하단 플로팅 바 (독):**
  * **`[📑 메뉴 · 현재페이지 ▲]`:** 권한이 허용된 1~7번 메뉴로 빠르게 이동합니다.
  * **`[🎵 BGM]` (배경음악 플레이어):** 유튜브 플레이리스트 URL (`youtube.com/playlist?list=...`), 영상 URL, 틱톡 링크 또는 개인 MP3 파일을 등록하여 메뉴 이동 시에도 끊김 없이 미니 팝업으로 음악을 연속 재생합니다.

### 📑 1~7번 메뉴별 핵심 가이드

#### 1. `1. 데이터 입력` (기초 데이터 통합 로딩)
* **1단계 (카톡 발주 파일 업로드):** 카카오톡 텍스트 내보내기 파일(`.txt`)을 여러 개 선택해 로딩합니다. 한 메시지에 수십 개 거래처가 섞여 있어도 자동으로 낱개 거래처 카드로 분할되며, 중복 주문 제거 및 `●추가` 발주는 기존 거래처 카드로 자동 합산됩니다.
* **2단계 (카톡 재고현황 로딩):** 텍스트 재고표를 붙여넣어 사내 데이터에 반영합니다. (`2. 엑셀 재고파악`을 이용하면 자동으로 생성되므로 이 과정이 생략됩니다.)
* **3단계 (거래처 CSV 연동):** `clients.csv` 파일 또는 URL을 통해 거래처 주소, 전화번호, 출입 비번 및 지도 데이터 베이스를 동기화합니다.

#### 2. `2. 엑셀 재고파악` (ERP 엑셀 → 카톡 재고표 생성 및 전산 반영)
* ERP 재고 엑셀 파일(`.xlsx`, `.xls`)을 드래그 앤 드롭으로 업로드합니다.
* **카톡 공유용 텍스트 자동 작성:** 전각 줄맞춤이 적용된 카톡 공유용 재고현황이 즉시 생성되며 **`[💬 카톡 공유용 복사]`** 버튼으로 카톡방에 전달 가능합니다.
* **`[✅ 사내 전산재고에 바로 반영]`:** 클릭 시 현재 엑셀 재고가 `5. 재고정리·창고랙`과 `6. 발주차감 잔여재고` 시스템에 실시간 연동됩니다.
* 행 단위 `+` 버튼으로 신규 메이커·상품코드를 즉시 삽입할 수 있으며, 하단 3열 요약표와 **`[🖨️ 한장 인쇄]`** 기능을 지원합니다.

#### 3. `3. 발주 추출 목록` (6열 바둑판 발주 확인)
* 추출된 일일 발주 내역을 6열 바둑판 카드로 시각화합니다.
* 카드의 헤더에 **`작성일시 | 거래처명 | [🚚당 / ⏭익] | 발주자`** 정보를 한눈에 제공합니다.
* 카드 상단의 **`[🚚당]`** 또는 **`[⏭익]`** 버튼을 터치하여 거래처별 납품 구분을 즉시 전환할 수 있습니다.

#### 4. `4. 낱개 목록` (작업·세절 및 소분 낱개 전용 체크리스트)
* 당일 발주 중 박스 단위가 아닌 팩, 판, kg, 소분 작업, 세절, 슬라이스, 제육, 찌개용 품목만 자동 분류합니다.
* **상단 필터:** `전체` / `🔪 작업·세절만` / `⚖️ 단순 낱개만`
* **보기 모드:** `🏢 거래처별` / `🥩 품목별` / `🚚 호차별` 6열 카드로 변환하여 현장 작업 및 출고 체크리스트로 활용합니다.

#### 5. `5. 재고정리·창고랙` (창고 3단 랙 · FIFO 실사 · 바코드 관리)
* **창고 3단 랙 배치 (`Zone L` / `Zone C` / `Zone R`):** 입구 기준 시계방향 동선의 `L-A1`~`R-C3` (1단 상단 · 2단 중단 · 3단 하단) 구역에 품목을 배치합니다. **`[🔄 전산재고 → 빈 랙 자동배치]`** 또는 각 랙의 `[-1]`, `[+1]`, `[✏️]` 조작으로 실시간 수량을 수정합니다.
* **선입선출(FIFO) 실사 관리:** 입고 후 경과일이 오래된 재고(`5일`, `6일` 등)에 **`⚠️ 선입선출 우선`** 빨간 배지를 표시합니다. 현장 실사 수량 입력 후 **`[✅ 실사수량 → 전산재고 반영]`**을 클릭합니다.
* **스마트 바코드 입출고:** 카메라 스캔 또는 USB 바코드 스캐너 인식 시 품목명, 메이커, 랙 위치, 재고 수량, 당일 발주량이 팝업에 즉시 출력되며 **`[➕ 입고(+1)]` / `[➖ 출고(-1)]`** 처리가 진행됩니다. 미등록 바코드는 현장 즉시 등록 및 라벨 인쇄가 가능합니다.

#### 6. `6. 발주차감 잔여재고` (과부족 수량 자동 계산)
* `현재 전산 재고 - 당일 전체 발주량`을 메이커/브랜드(대산·포크·기타 등)별로 자동 차감 계산합니다.
* 발주량 대비 재고가 모자라는 품목은 **`부족!`** 빨간 배지로 경고하여 추가 수급 및 세절 수량을 빠르게 판단할 수 있습니다.

#### 7. `7. 배송처 목록·배차` (1~6호차 자동 배차 & VWorld 지도 연동)
* **스마트 자동 배차:** 1~6호차 운전 기사 지정 및 냉장창고 4곳 경유 여부 선택 후 **`[🧭 권역·동선별 스마트 자동배차]`**를 실행하면 배송 지역과 이동 동선에 맞춰 차량이 자동 배정됩니다.
* **VWorld 지도 및 상세 정보 인터랙션:**
  * 각 카드 및 배차 목록의 **`[📍 주소]`** 버튼 클릭 시 해당 거래처의 주소, 전화번호, 출입 비번 및 VWorld 지도가 해당 위치로 이동 핀포인팅됩니다.
  * 6열 배차 카드 하단의 `1`~`6` 숫자 버튼을 터치하여 수동으로 호차를 자유롭게 변경할 수 있습니다.
