# 발주 정리 (카톡 → 박스 / 낱개 / 메이커)

카카오톡 발주방 대화 내보내기(txt)를 올리면 **전날 12:00 ~ 발주일 16:00** (월요일은 금요일 12:00부터) 메시지만 읽어서 정리합니다.
대화 내용은 기기 안에서만 처리되고 서버로 전송되지 않습니다.

## 분류 규칙
| 분류 | 기준 | 예시 |
|---|---|---|
| 발주(박스) | 숫자 뒤에 박스/박/빡스가 있거나 아무 표기가 없음 | `삼겹 5박스`, `등심2` |
| 낱개 | 숫자 뒤에 박스 외 단위 (팩·봉·판·kg·덩이·벌·마리 …) | `항정 3팩`, `항정 5키로` |
| 메이커 | 낱개가 아니면서 메이커(대산·포크·정담·테니쉬·토레인…)가 적힌 것 | `삼겹3 포크`, `토레인 삼겹2박스`, `삼겹 15박스(포크10 정담5)` |

- 한 줄에 박스와 낱개가 같이 있으면 둘로 나눕니다 (`왕구이 2박스 2팩`).
- 낱개와 메이커가 같이 있으면 낱개로 분류합니다.
- 메이커 단어는 앱 ⚙ 설정에서 추가/삭제할 수 있습니다.
- 소수점이 든 줄(`특삼 20포 19.9`)과 4자리 숫자 줄(계근)은 발주로 읽지 않습니다.
- 애매한 줄은 **확인** 탭에 모아 보여줍니다 (수량 미기재, 숫자가 여러 개, 거래처 불확실).
- `수요일` 같이 발주일보다 뒤 날짜가 적힌 발주와 똑같이 다시 올라온 발주는 기본으로 제외하고 **확인** 탭에 보여줍니다.

## 사용법
1. 처음 한 번: `미트앤포거래처.csv` 선택 (이 기기에 저장됨, 열: 거래처명 / 주소 / 별명)
2. 카톡 방 → ⋮ → 대화 내보내기 → 텍스트 메시지만 → 저장한 txt 선택
3. 날짜는 자동으로 잡히고, 바꾸고 싶으면 날짜 칸을 누르세요
4. 탭: 발주(박스) / 낱개 / 메이커 / 배송지별 전체 / 확인 — 각 탭에서 **물품별 ↔ 배송지별** 전환, **복사·공유** 가능
5. 카톡에 쓴 줄임말(예: `농민마트와동`)이 거래처 목록과 안 맞으면 **확인** 탭에서 한 번만 지정하면 기억합니다
   (⚙ → "별명 포함 거래처 CSV 저장"으로 CSV의 별명 열에 백업 가능)

## 깃허브(GitHub Pages)로 올리기
1. GitHub에서 새 저장소 만들기 (이름 예: `order-organizer`)
2. **Add file → Upload files** 로 이 폴더의 파일 올리기: `index.html`, `parser.js`, `sw.js`, `manifest.webmanifest`, `icon-*.png`, `README.md`
3. **Settings → Pages → Branch: main / (root)** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/order-organizer/` 접속
5. 폰 크롬에서 열고 ⋮ → **홈 화면에 추가 / 앱 설치** → 앱처럼 실행 (오프라인도 가능)

> 저장소를 **Public**으로 만들어도 거래처 정보는 올라가지 않습니다. CSV는 앱에서 각자 기기로만 불러오는 구조예요. (CSV 파일 자체를 저장소에 올리지 마세요.)

## APK가 필요할 때
위 주소가 생기면 [pwabuilder.com](https://www.pwabuilder.com)에 주소를 넣고 Android 패키지를 만들면 APK/AAB를 받을 수 있습니다. (이 환경에서는 APK 빌드를 직접 시험하지 못했습니다.)
